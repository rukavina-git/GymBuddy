# Security Policy

## Supported versions

Only the latest `main` (and the backend running from it at
`https://api.rukavina.app`) gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
([private vulnerability reporting](https://github.com/rukavina-git/GymBuddy/security/advisories/new)).

Include what you found, how to reproduce it, and what an attacker could
do with it. You'll get a reply within 7 days. Once a fix is out, the
advisory is published and you're credited unless you'd rather not be.

Please don't test against other users' accounts or data, and don't run
load or denial-of-service tests against the hosted backend.
