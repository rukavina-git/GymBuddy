# 1. Client-generated UUIDv7 identifiers

Date: 2026-08-09
Status: Accepted

## Context

Entities are created on-device while offline and reconciled with a
server later. Server-assigned integer keys cannot work: two devices
offline would assign the same value, requiring an ID-remapping pass
that rewrites every foreign key referencing the entity.

## Decision

All entity identifiers are UUIDs generated by whoever creates the
entity — clients for user data, server for reference data. Version 7
(RFC 9562) rather than 4, for the embedded millisecond timestamp.

Implemented in-project rather than via a dependency; the generator
is ~20 lines and is needed again in Swift.

## Consequences

- Entity ID doubles as the sync idempotency key.
- Time-ordered IDs keep Postgres B-tree inserts local.
- Storage cost over an integer key is accepted as negligible here.
- Ordering within a single millisecond is not guaranteed —
  rand_a is random rather than a monotonic counter.
