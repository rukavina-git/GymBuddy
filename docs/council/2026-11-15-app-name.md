# Council 2026-11-15: App name (GymBuddy vs Gym Buddy vs new)

7 members (6 standard + brand/ASO/trademark), 1 round.

## Brief
```
COUNCIL BRIEF: the app's public name (GymBuddy, native Android, solo developer in Croatia, EU)

Decision:
Q1 Name direction:
 (a) "GymBuddy" (one word, as the app shows today)
 (b) "Gym Buddy" (two words, as the placeholder Play title says)
 (c) Keep GymBuddy + a descriptor in the Play title, e.g. "GymBuddy: Workout Log" / "GymBuddy - Offline Lift Log"
 (d) New distinct name before closed testing (give 1-3 concrete candidates if you pick this)
Q2 If the name stays GymBuddy-like: (a) do nothing more, (b) also put a distinct developer name and icon forward, (c) plan a rename later (after v1) if a conflict comes up.

Facts (researched 2026-11-15):
- Live on Google Play: "Workout Log - Gym Buddy" (razielkatz.gymbuddy, ~74K installs, 4.5*, minimalist sets/weight/reps logger: very close to us; also on iOS as "Gym Buddy - Workout Log").
- Live on Play: "GymBuddy: Guided Strength" (com.kate.gymbuddy, launched Oct 2026, free, no ads).
- iOS: "GymBuddy" by GymBuddy Health & Fitness Ltd (UK), listing shows "GymBuddy®". Others: "GymBuddy - Log workouts easy", "Workout Buddy", "Fitness Buddy", "MyGymBuddy" (US TM filing). Several USPTO "GYMBUDDY"/"GYM BUDDY" filings exist; EUIPO not checked.
- Play policy: titles should be unique; no hard ban on shared names, but impersonation/misleading-title enforcement exists and some devs report suspensions over a name alone.
- Locked: package id com.rukavina.gymbuddy (already uploaded, can never change; invisible to users). Internal code names stay. Domain rukavina.app (legal pages at rukavina.app/gymbuddy/...). iOS app comes later. Owner wants to keep monetization possible later (paid features/ads).
- Status: internal testing only; store listing not filled; closed testing (12 testers) and production are next. Renaming now costs strings, launcher label, legal pages, Figma, listing; renaming after launch costs reviews/users' recognition.

Read: PRODUCT.md, docs/plans/figma-foundation/design-brief.md (skim), android/fastlane/metadata/android/en-US/*.txt.
```

## Answers (as reported)

**Design director (impeccable):** VOTE Q1 d, Q2 b as fallback.
Fails the slop test (critique.md:137 "authored for this product, or
category-interchangeable"; shape.md:23 "uniquely true here"): the
74K-install "Workout Log - Gym Buddy" is the same minimal logger with
the same name. "Buddy" contradicts PRODUCT.md "No social layer… A
tool, not a network". Name should match the tool voice ("The set is
sacred", honest history). Candidates: Setkeep, Tally Lift, Repledger.
Risk: PRODUCT.md locks "Name: GymBuddy"; only the owner lifts it.
Veto: b (near-copy title, misleading-title enforcement). Idea: test
finalists as real launcher labels (~12 chars) and in Play search.

**Product owner:** VOTE Q1 d, Q2 b as fallback. Same pitch as the
74K app; searches for "gym buddy" go to them, reviews get confused.
UK "GymBuddy®" + US filings: a forced rename after paid features or
ads is the costliest case and breaks the no-monetization-blockers
rule. Renaming now: strings, launcher label, listing, the "gymbuddy."
wordmark; package id and rukavina.app/gymbuddy/ URLs stay; lime dot
and ECG logo carry over. Candidates: Repline (matches ECG line logo),
Liftline, Setwise. Risk: ~1 step before 9.5; unscreened new name.
Veto: b. Idea: roadmap 9.4a one-hour name check (Play, App Store,
TMview classes 9/42, domain) before locking.

**Android architect:** VOTE Q1 c, Q2 b. Name is in few places:
`app_name`, qa "GymBuddy Test", 4 strings (onboarding, you), 2
hardcoded (AboutScreen feedback subject, a log line), fastlane title +
description, ~9 mentions in legal/. Play title and launcher label can
differ, so (c) costs only metadata ("GymBuddy: Offline Workout Log",
29 chars). Real rename cost is design: wordmark, "G" icon, Figma.
Found: `app_name` and title.txt say "Gym Buddy" (two words), in-app
copy, legal and wordmark say "GymBuddy": fix either way. Risk: close
to the 74K app, could draw a misleading-title report and force a
rename after reviews exist. Veto: b. Idea: name in one place
(`app_name`, `%1$s` in strings, a variable in legal/build.py).

**Accessibility:** VOTE Q1 d, Q2 b as fallback. `app_name` is "Gym
Buddy", identical to the 74K app's label: launcher, TalkBack and app
search show two identical entries. "Hey Google, open Gym Buddy" can't
tell lookalikes apart. A Play-title descriptor (c) never reaches the
launcher, TalkBack or voice. New name: one spoken word, one obvious
pronunciation, ≤8 chars. Candidates: Setwise, Repbook, Liftly. Veto:
b. Idea: test finalists on the phone with the lookalike installed:
TTS and "Hey Google, open X".

**Beginner lifter:** VOTE Q1 d, Q2 b. I search "workout log", find
the 74K app and never see yours; a friend's "get GymBuddy" sends me to
the wrong one; three lookalikes look like a scam copy. A rename after
launch feels sketchy. Candidates: Repwise, Steady Sets, Barbook. Risk:
a coined name doesn't say "gym", needs a descriptor. Veto: b. Idea:
say the name to a few newbies, ask them to find it on Play.

**Veteran lifter:** VOTE Q1 d, Q2 b as fallback. Next to Strong and
Hevy, "GymBuddy" reads as a beginner companion or partner finder, not
a tool; word of mouth sends friends to the competitor. Candidates:
Setbook, Liftline, Repwise. Risk: one more step, new name needs EUIPO
and Play checks. Veto: b. Idea: search test on a clean phone; if we're
not the top hit for the exact name, it fails.

**Brand / ASO / trademark:** VOTE Q1 d. Confusion risk high (74K app,
same job; "GymBuddy: Guided Strength" also live). US filings (pending
"GYM BUDDY" class 9, May 2026; "MYGYMBUDDY"), UK "GymBuddy®"; no EU
filing found, TMview not checked directly. "Gym buddy" is near-generic:
we could never register it, which blocks paid tier/ads later. We can't
win search for our own name. Candidates (no exact-name app on Play or
iOS): Steadyset, Liftlore, Setkeep (close to iOS "LiftKeeper"). Risk:
web searches only, not a TMview/EUIPO/USPTO search. Veto: b. Idea:
TMview the shortlist, buy the matching domain; file one EU mark
(classes 9 + 42, ~€850) before going paid.
